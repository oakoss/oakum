---
oakum: major
---

oakum reads its version from the install pin, not `tool-version` (ADR-0038). `add`, `generate`, `version`, `ci version-pr`, `release`, `upgrade`, `init`, and `migrate` compare this binary to the version pinned in `.github/workflows`, a composite action under `.github/actions`, `package.json`, `.mise.toml` or `mise.toml`, or a Cargo workspace member named `oakum`, and refuse with exit 1 when they differ, naming the fix for that direction. `add`, `generate`, `version`, and `ci version-pr` refuse with exit 2 when nothing pins oakum, when pins disagree, or when a pin cannot be read or is a range such as `^0.5.0`; a repository that relied on `tool-version` alone with a global or Homebrew install now needs a pin: `pnpm add -D @oakoss/oakum@<version>`, or `"github:oakoss/oakum" = "<version>"` under `[tools]` in `.mise.toml`. A symlink to a missing target where a pin source would be is unverified, as a pin that cannot be read is, not read as no pin; `check` included. `upgrade` refuses with exit 2 when pins disagree or cannot be read; when nothing pins oakum it continues and says so on stderr. `release` leaves a missing or unsettled pin to its install-pin precondition, as before. `init` and `migrate` check the pin on every run, a fresh repository included, and write their files whatever the pin says unless it names another version: with no pin they print the pin as the next step and exit 0, pointing at the printed workflow's install line when it has one, and when pins disagree or cannot be read they print that and exit 2 after writing. `check` passes pins that agree with each other whatever `tool-version` says, and reads `github:oakoss/oakum` as a pin. `init` and `migrate` no longer write `tool-version` into the `_config.toml` they create. `_config.toml` may omit `tool-version`, and any value in it parses, a range included: nothing reads it, `upgrade` reports a config without it as current, and the schema no longer requires it. While the key is present, every command that loads the config except `upgrade` prints one stderr line saying oakum no longer reads it and naming `oakum upgrade`; exit codes and stdout are unchanged. The version-PR body and changelog footer stamp this binary's version.
