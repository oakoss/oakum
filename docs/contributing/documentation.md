# Documentation

[`docs/README.md`](../README.md) explains the layout and which directory a given document belongs in.

Before changing behavior, check [`docs/decisions/`](../decisions/) — a decision recorded there was expensive to reach, and several encode findings that took real verification to establish. Contradicting one means writing a new ADR that supersedes it, not quietly diverging.

Claims about external tools belong in [`docs/research/`](../research/) with their sources. An undated or unsourced finding is worse than none.
